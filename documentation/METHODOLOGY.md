# Methodology

1. Preserve the original fictional case inputs and submitted scoring matrix.
2. Validate scoring criteria weights total 1.0 and criterion scores fall between 1 and 5.
3. Calculate weighted totals = Σ(criterion score × criterion weight).
4. Rank all four opportunities descending by weighted score.
5. Test the original submitted sensitivity assumption: Customer Enquiry Automation readiness 3 → 1, all else fixed.
6. Interpret the reversal as conditionality, not a statistical confidence interval.
7. Present a bounded 90-day supervised pilot and proposed KPI thresholds, without inventing actual results.

## Criterion weights
Business value 30%; data readiness 20%; feasibility 20%; risk manageability 15%; time to value 15%.

## Score meaning
1 = weak/major challenge, 3 = moderate/partially ready, 5 = strong/highly ready. Scores are candidate judgments. The rationale table in the notebook is explanatory portfolio interpretation, not a verbatim extract from the submitted workbook.

## Known limitations
Small number of subjective alternatives; no verified underlying transactional data; no uncertainty distributions; potential rank sensitivity to criterion weights and readiness; vendor quotes and ROI unverified.
